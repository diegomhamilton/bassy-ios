# V0.4 — Backing Tracks

[[../implementation-plan|← Plan index]]

## Product milestone

V0.4 adds imported backing tracks to the established recording, looping, and metronome workflow.

The user can:

1. import a supported audio file;
2. retain a managed copy of the imported track;
3. play, pause, stop, and seek within the track;
4. control backing-track volume independently;
5. play along using live monitoring, loops, and the metronome;
6. save and restore the backing track as part of a session.

## V0.4 RELEASE GATE

The following workflow must work:

```text
Open or create session
       ↓
Import supported audio file
       ↓
Play, pause, and seek
       ↓
Set backing-track volume independently
       ↓
Play live instrument with track
       ↓
Use loops and metronome with track
       ↓
Save and close session
       ↓
Reopen session
       ↓
Backing-track association restores correctly
```
